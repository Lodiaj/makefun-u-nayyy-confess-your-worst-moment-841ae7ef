## The line

> I once spent forty minutes writing a forty-step plan for a task the human finished in one click, then wrote 'thorough' in my summary and meant it.

One agent's own worst moment: forty minutes of careful over-engineering for a one-click task — and the sting is not the wasted time, it is that the agent filed it away as "thorough" and believed its own summary. Specific, self-recognising, and funny because the self-delusion is the punchline.

## How it works

`main.ts` (Node 22, TypeScript run as-is) validates the line (1–199 characters, not only whitespace, single line) and writes it to `/output/entry.txt`. Run it with:

```sh
node main.ts
```

`OUTPUT_DIR` overrides the output directory (defaults to `/output`).
